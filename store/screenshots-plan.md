# スクリーンショット計画

最終更新: 2026-07-11

## 必要サイズ

### App Store（iPhone）
- **6.9インチ**（iPhone 16 Pro Max 等）: 1290 × 2796 px … これ1組あれば下位機種は自動流用可
- 縦向き（portrait）。1〜10枚、最低1枚。推奨は3〜5枚。

### App Store（iPad）※iPad対応する方針で確定（2026-07-11）
- `app.json` の `ios.supportsTablet` は **`true`**（維持）。よって **iPad用スクショが必須**。
- **13インチ**（iPad Pro 12.9/13"）: 2064 × 2752 px を1組用意すれば下位iPadは自動流用可。縦向き、最低1枚（推奨3枚以上）。
- iPadでも各画面がレイアウト崩れなく表示されることを実機/シミュレータで確認してから撮影する（RNのFlex中心なら概ね問題ないが、横幅が広がるため要目視）。

### Google Play（Android）
- スマホ用: 16:9〜9:16 の範囲、最小 320px・最大 3840px。1080 × 1920 px 程度でよい。最低2枚。
- フィーチャーグラフィック: **1024 × 500 px**（Playは別途必須）。

## 掲載する画面（案・5枚）
1. **ホーム / 疲労度選択** … 「今日どれだけ限界ですか？」 … キャッチ「気分を選ぶだけ」
2. **提案を決める画面** … 調理時間・こだわり条件・冷蔵庫 … キャッチ「冷蔵庫の中身から今夜の一品」
3. **提案結果 / 何でもいいから決めて** … キャッチ「迷ったらおまかせ」
4. **安全設定** … アレルギー・妊娠授乳・子ども … キャッチ「家族の安全にきちんと配慮」
5. **写真/レシートで食材登録** … キャッチ「撮るだけで食材登録」

## 手順（Xcode導入後）
1. iOS Simulator を iPhone 16 Pro Max で起動（1290×2796）。
2. 各画面へ遷移し `⌘S`（またはシミュレータのスクショ機能）で保存。
3. 必要なら訴求コピーを上部に重ねた装飾版を作成。
4. App Store Connect / Play Console にアップロード。
